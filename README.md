## 📦 Installation

### Requirements
- Python 3.6+
- `pip3`
- Linux / macOS / Windows (WSL recommended)

### Quick Install

```bash
# Step 1: Clone the repository
git clone https://github.com/antlynnaung35-code/APEX-ETERNAL-ULTIMATE-EDITION.git

# Step 2: Navigate to the project directory
cd APEX-ETERNAL-ULTIMATE-EDITION

# Step 3: Install required dependencies
pip3 install -r requirements.txt

# Complete scan with all modules
python3 zeusapex_ai_v26000.py -t http://www.example.com

# Autonomous mode (unstoppable)
python3 zeusapex_ai_v26000.py -t http://example.com --autonomous

# Safe mode (read-only testing)
python3 zeusapex_ai_v26000.py -t http://example.com --safe-mode --non-destructive

# With authorization tracking
python3 zeusapex_ai_v26000.py -t http://example.com --authorized-by "Your Name" --autonomous

# Custom port
python3 zeusapex_ai_v26000.py -t https://example.com --port 443 --autonomous

# Stealth with rate limiting
python3 zeusapex_ai_v26000.py -t https://example.com --stealth --rate-limit 3 --autonomous
